# SV Store — интернет-магазин аксессуаров для ПК и ноутбуков

Это ваш существующий сайт, разделённый на отдельные файлы. Дизайн, товары, корзина, оформление заказа, поиск и остальные функции остались без изменений. Изменилась только структура файлов.

---

## 1. Структура проекта

```
SV-STORE/
├── index.html            Главная страница: структура сайта (HTML) и подключение всех файлов
├── README.md             Эта инструкция
├── css/
│   ├── style.css         Основной дизайн: цвета, шрифты, карточки, кнопки, шапка, корзина, светлая и тёмная темы
│   └── responsive.css    Адаптация под телефоны и планшеты (подключается после style.css)
├── js/
│   ├── products.js       Все товары, категории, ссылки на фото, скидка сайта, каталог
│   ├── utils.js          Общие функции: сохранение данных, форматирование цены, тема, уведомления
│   ├── cart.js           Корзина: добавление, количество, удаление, очистка
│   ├── builder.js        Конструктор сетапа: подбор товаров по бюджету
│   ├── home.js           Главная страница: каталог, конструктор, «О магазине», доставка, FAQ
│   ├── product.js        Страница одного товара
│   ├── profile.js        Личный кабинет: вход, регистрация, история заказов
│   ├── checkout.js       Оформление заказа
│   └── main.js           Запуск сайта: переключение страниц, клики, поиск, таймер акции
└── images/
    └── products/         Папка для своих фото товаров (сейчас пустая, см. раздел 5)
```

Папки `images/banners` и `images/icons` не созданы, потому что в вашем сайте пока нет баннеров и своих иконок. Если понадобятся, их можно создать.

## 2. Что отвечает за каждый файл

**index.html** — каркас сайта. Здесь находятся шапка с меню, боковая панель корзины, всплывающие уведомления и подключение всех файлов. Сами товары здесь не хранятся.

**css/style.css** — внешний вид. Цвета задаются переменными в начале блока `:root` (тёмная тема) и `:root[data-theme="light"]` (светлая тема). Чтобы поменять цвет кнопок, ищите `--grad` и `--cyan`.

**css/responsive.css** — правила для маленьких экранов. Например, на телефоне меню скрывается, а карточки становятся меньше.

**js/products.js** — самый важный файл для ежедневной работы. Здесь:
- `CATEGORIES` — список категорий (кнопки-фильтры);
- `PRODUCTS` — список товаров;
- `SITE_DISCOUNT` — размер скидки на весь сайт (сейчас 0.15, то есть 15 %);
- `PHOTOS` — ссылки на фото товаров;
- `BUILD_ORDER` — категории, которые участвуют в конструкторе сетапа.

**js/utils.js** — вспомогательные функции. Сюда входят `store` (сохранение в браузере), `money` (вывод цены в гривнах), `esc` (защита текста от вставки кода), `showToast` (уведомления справа внизу), переключение темы.

**js/cart.js** — корзина. Товары хранятся в браузере под ключом `sv_cart`. Здесь же считается итоговая сумма.

**js/builder.js** — конструктор сетапа. Берёт бюджет и выбранные категории, подбирает товары так, чтобы сумма не превышала бюджет.

**js/home.js** — главная страница: заголовок, каталог с поиском и фильтрами, конструктор, блоки «О магазине», «Доставка та оплата», FAQ и футер.

**js/product.js** — страница товара: фото, описание, характеристики, кнопка «В корзину», похожие товары.

**js/profile.js** — личный кабинет. Пользователи и их заказы хранятся в браузере, это не настоящая база данных.

**js/checkout.js** — форма оформления заказа: имя, телефон, адрес, доставка, оплата и итоговая сумма.

**js/main.js** — запуск сайта. Здесь переключение страниц по адресу (`#/product/1`, `#/checkout` и т. д.), обработка нажатий, живой поиск с подсказками, таймер акции. Этот файл подключается последним.

## 3. Как открыть и запустить

### Вариант А: двойной клик
Откройте папку `SV-STORE` и дважды нажмите на `index.html`. Сайт откроется в браузере.

### Вариант Б: Visual Studio Code (рекомендуется)
1. Установите Visual Studio Code с официального сайта code.visualstudio.com.
2. В меню выберите **File → Open Folder** и откройте папку `SV-STORE`.
3. Установите расширение **Live Server** (вкладка Extensions, слева).
4. Нажмите правой кнопкой мыши на `index.html` и выберите **Open with Live Server**.

Live Server обновляет страницу сам при сохранении файлов, поэтому удобно видеть изменения сразу.

### Важно про интернет
Шрифты (Inter, Montserrat) и фото товаров загружаются из интернета. Без интернета сайт будет работать, но шрифты и фото не отобразятся.

## 4. Как добавить новый товар

Откройте `js/products.js`, найдите блок `PRODUCTS.push(` и добавьте строку по образцу:

```js
P(49, "mice", "Название товара", "Краткое описание.", 999, null, "МЕТКА", [["Подключение", "Беспроводное"]]),
```

Что означают значения по порядку:
- `49` — номер товара. Он должен быть уникальным, то есть не повторять номера других товаров.
- `"mice"` — ключ категории. Допустимые ключи: `mice`, `keyboards`, `hubs`, `stands`, `storage`, `cables`, `mousepads`, `headphones`, `headsets`, `mics`, `gamepads`, `pcacc`.
- `"Название товара"` — название, которое видит покупатель.
- `"Краткое описание."` — описание.
- `999` — цена в гривнах. Скидка 15 % применяется автоматически.
- `null` — старая (зачёркнутая) цена. Если она есть, напишите число, например `1299`.
- `"МЕТКА"` — короткая подпись на карточке без фото.
- `[["Подключение", "Беспроводное"]]` — характеристики. Можно добавить несколько пар через запятую.

Не забудьте добавить строку с фото в `PHOTOS` (см. раздел 5), иначе будет цветная заглушка.

Чтобы добавить новую категорию, добавьте её в `CATEGORIES` в начале `products.js`:

```js
{ key: "webcams", title: "Веб-камеры" }
```

## 5. Как вставить фото товаров

Все фото прописаны в `js/products.js` в блоке `const PHOTOS = { ... }`. Номер слева — номер товара, справа — ссылка:

```js
  1: "https://example.com/mu105.jpg", // Беспроводная мышь UGREEN MU105 Blue
```

Есть два способа:

1. **Ссылка из интернета.** Откройте картинку в браузере, нажмите на неё правой кнопкой и выберите «Копировать адрес изображения». Вставьте адрес между кавычками.
2. **Свой файл.** Положите картинку в папку `images/products/`, например `mu105.jpg`. В `PHOTOS` напишите `"images/products/mu105.jpg"`.

Советы по фото:
- лучше квадратные, от 800×800 пикселей;
- товар снимайте по центру, потому что фото обрезаются по центру;
- PNG с прозрачным фоном хорошо смотрятся на цветном фоне карточки.

Чтобы убрать фото у товара, сделайте значение пустым: `""`.

## 7. Порядок подключения файлов (очень важно)

В `index.html` скрипты подключаются в таком порядке:

1. `products.js` — данные о товарах
2. `utils.js` — общие функции
3. `cart.js` — корзина
4. `builder.js` — конструктор
5. `home.js` — главная страница
6. `product.js` — страница товара
7. `profile.js` — личный кабинет
8. `checkout.js` — оформление заказа
9. `main.js` — запуск

Файлы используют функции и данные из предыдущих файлов. Если поменять порядок, сайт перестанет работать, и в консоли появится ошибка. Если вы добавляете новый файл, подключите его до `main.js`.

Стили подключаются в порядке: сначала `style.css`, потом `responsive.css`. Это тоже важно, потому что адаптивные правила должны идти последними.

## 8. Как проверить, что сайт работает

1. Откройте сайт и убедитесь, что на главной видны карточки товаров.
2. Нажмите «+» на любой карточке: появится уведомление справа внизу, в корзине — товар.
3. Откройте корзину, увеличьте количество кнопкой «+» и проверьте, что сумма изменилась.
4. Обновите страницу (F5): корзина должна остаться.
5. Выберите категорию в фильтрах и введите слово в поиск.
6. Откройте любой товар и нажмите «Назад к каталогу».
7. Откройте консоль браузера (F12, вкладка Console). Ошибок быть не должно.

## 9. Ограничения

- **Нет сервера и базы данных.** Корзина, аккаунты и заказы хранятся в браузере конкретного устройства. Если очистить данные браузера, они пропадут. Сейчас это не настоящие заказы, которые приходят продавцу.
- **Цены и описания** новых товаров ориентировочные. Их нужно проверить перед запуском.
- **Фото** по ссылкам из интернета могут исчезнуть, если сайт-источник их удалит. Для надёжности лучше сохранить фото в `images/products/`.
- **Шрифты** подгружаются из интернета.
- **Кнопка «Оплата» и отправка заказа** не подключены к платёжной системе или Telegram-боту.
